# The lethal trifecta

An agent is dangerous when one session holds all three: private data, untrusted input, and a way out (network, email, a
tool that posts). Injected text can then read the data and send it out.

Cut one leg per job. The email job has no access to the brain; the triage job has no network.

Where an agent holds all three on purpose (a chat), accept the risk in writing and watch for it: a tripwire that alerts
when a tool call carries a long run of words from a note, and a canary link in the brain that alerts when anything
opens it.
